# Katta Sai Reshmi — Futuristic Data Analyst Portfolio

A visually stunning, award-winning creative developer personal portfolio with a **futuristic dark cyber aesthetic**, sophisticated animations, interactive 3D physics, and smooth transitions. Built with **React**, **Vite**, **Tailwind CSS**, **Framer Motion**, and **GSAP**.

Designed around the genuine credentials and data extracted directly from **Katta Sai Reshmi's Resume** and the **Electronics store dataset.xlsx**.

---

## 🌌 Design & Aesthetic Highlights

- **Aesthetic**: Premium futuristic dark theme inspired by Awwwards-winning developer portfolios.
- **Color Palette**: Deep Obsidian & Charcoal backgrounds (`#030712`, `#070b14`), accented with vibrant Neon Cyan (`#00f0ff`), Violet (`#a855f7`), and Electric Blue (`#38bdf8`).

## ⚡ Animations & Interactions

1. **Cinematic Loading Terminal (`Preloader.jsx`)**:
   - Initial boot sequence simulating neural data core initialization.
   - Smooth numerical counter (0% → 100%) with status telemetry and ESC skip option.
2. **Custom Animated Cursor (`CustomCursor.jsx`)**:
   - Smooth mouse-following precision dot and trailing spring halo ring.
   - Reactive expansion and color-shift over interactive elements.
   - Auto-disabled on mobile/touch screens for clean responsive UX.
3. **Ambient Mouse Spotlight (`MouseSpotlight.jsx`)**:
   - Dynamic flashlight gradient tracking user cursor across cards and glass panels.
4. **Interactive Neural Network Canvas (`InteractiveBackground.jsx`)**:
   - HTML5 Canvas particle constellation that repels and connects with dynamic glowing cyber lines.
5. **3D Tilt Cards (`TiltCard.jsx`)**:
   - Multi-axis perspective tilt with specular sheen reacting to cursor position.
6. **Magnetic Interactive Buttons (`MagneticButton.jsx`)**:
   - Spring physics magnetic pull toward mouse cursor with synthesized sound effects.
7. **Synthesized Web Audio FX (`sound.js`)**:
   - Non-intrusive futuristic cyber click, hover, and chime audio synthesized entirely in browser via Web Audio API, with an explicit sound mute/unmute control in the navbar.
8. **Celebration Confetti Burst**:
   - Interactive transmission dispatch celebration on the contact form using `canvas-confetti`.
